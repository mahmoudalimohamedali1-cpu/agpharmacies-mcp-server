# AG Pharmacies Medical & Drug Alternatives MCP Server

🌐 **Official Website:** [https://agpharmacies.com](https://agpharmacies.com)

An open Model Context Protocol (MCP) reference connector for querying the Arabic Medical Encyclopedia, Egyptian Drug Alternatives Index, and Pediatric Fever Dosage Calculator by **آية العناني — صيدليات عبدالخالق وجمال (AG Pharmacies)**.

## Features & Endpoints
- **Drug & Product Search:** Queries [https://agpharmacies.com/search](https://agpharmacies.com/search) and [https://agpharmacies.com/shop](https://agpharmacies.com/shop)
- **Egyptian Drug Alternatives (by Active Ingredient):** [https://agpharmacies.com/alternatives](https://agpharmacies.com/alternatives)
- **Pediatric Fever Dose Calculator (Paracetamol & Ibuprofen):** [https://agpharmacies.com/tools/hasibat-jurat-khafid-alhararah](https://agpharmacies.com/tools/hasibat-jurat-khafid-alhararah)
- **Medical Encyclopedia (Diseases, Guidelines, Organs, Body Chemistry):**
  - [Diseases (الأمراض)](https://agpharmacies.com/diseases)
  - [Clinical Guidelines (الإرشادات العلاجية)](https://agpharmacies.com/guidelines)
  - [Human Body Map (أعضاء الجسم)](https://agpharmacies.com/body)
  - [Body Chemistry (كيمياء الجسم)](https://agpharmacies.com/chemistry)
  - [Regional Drug Guides: UAE](https://agpharmacies.com/drugs-uae) | [Saudi Arabia](https://agpharmacies.com/drugs-sa) | [Algeria](https://agpharmacies.com/drugs-dz)
